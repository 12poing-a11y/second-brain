## 2. 价格驱动归因：按对CF2701边际影响排序

### 第1位：中国新棉供给与商业库存累积

- **方向/等级：偏空，高。**
- **事实：** Mysteel统计11/20全国商业库存481.76万吨，环比+41.15万吨；新疆386.27万吨（+45.70）、内地38.29万吨（-3.40）、港口57.20万吨（-1.15），分项加总481.76万吨。中国棉花协会11/23周报口径截至11/22全国累计公检407.1万吨；另一公开跟踪源截至11/23约415.91万吨，统计截点不同，不能拼接成同一序列。
- **预期差：** 新棉集中入库速度快于现货销售消化；11/20皮棉销售进度约12.4%，11/23行业报道仍低于15%。中国棉花市场监测系统/行业估算的2026/27全国产量约733.7万吨、其中新疆约696.6万吨，属于行业预测，不是国家统计局最终产量。
- **传导链：** 采收/加工/公检放量 → 轧花厂和贸易商库存上升 → 现货议价压力及基差走弱 → CF2701上方套保和现货卖盘增加 → 中期估值承压。
- **对CF2701：** 若商业库存继续以较快速度增长、皮棉销售率仍低于15%，对估值的压制有望超过150点；缺少连续周度库存与销售弹性参数，暂不报精确点数。
- **计价程度：** 部分计价；期货仍明显低于现货指数，但现货基差正在收窄。
- **反证：** 商业库存连续回落、纺企补库/开机率上升、基差重新走阔。
- **下一验证：** 11/27前后Mysteel商业库存周报、棉花协会公检/销售周报、纺企开机和纱线库存。

### 第2位：纺织需求和替代纤维竞争

- **方向/等级：偏空，中高。**
- **事实：** 10月棉纺PMI 37.99，环比-5.79；Mysteel截至11/20纺企开机率66.8%（-0.4个百分点）、织布开机率27%（-1.8个百分点）；纱线库存39.48天。11/24 C32S约22,877元/吨、CY2701约20,780元/吨。
- **预期差：** 订单和名义出口仍有增长，但开机率与库存显示实物消耗没有同步改善。10月棉制品出口66.40万吨、同比+9.21%，出口金额同比+15.26%，但环比量减少5.67%；不能把棉制品出口增速直接等同于国内原棉消费增速。
- **替代纤维：** 涤纶短纤最近可核验8,447元/吨（11/20），粘胶短纤14,850元/吨（11/16）；报价日期不一致，暂不计算精确棉涤价差。涤纶价格偏低，对中低支纱有替代压力；棉花品质和订单结构决定替代弹性。
- **传导链：** 订单不足/纱线库存偏高 → 纺企降低开机和原料采购 → 棉花现货成交减弱 → 基差回落 → 期货反弹缺少现货跟涨。
- **对CF2701：** 方向性偏空；未取得纺纱利润、订单取消率和原棉实际消耗量，不报点数。
- **反证：** 开机率连续回升、纱线库存明显下降、C32S和坯布价格同步企稳、实际出口装运加快。

### 第3位：仓单注销后新棉注册缓慢

- **方向/等级：短期偏多，中高。**
- **事实：** 11/20陈棉集中注销后，11/23注册仓单59张（+21），11/24仍为59张；有效预报由277张升至296张（+19）。11/24注册仓单全部为26/27年度新棉。
- **预期差：** 全国新棉公检量已超过400万吨，但注册仓单只有59张，注册渗透率极低；这说明仓单生成受品质、货权、地点、流程和经济性约束，不能解释为新棉产量少。
- **传导链：** 陈棉注销 → 旧仓单退出 → 新棉注册速度低 → CF2701交割资源短期偏紧 → 近月价差和交割稀缺溢价上升。
- **对CF2701：** 对近月结构有支撑；缺少可交割现货、仓库容量和交割净回款全量数据，不单独量化稀缺溢价，避免与现货基差重复计价。
- **计价程度：** 已有部分计价；11/23价差430元/吨处于近五年同期高位。
- **反证：** 有效预报快速转为注册仓单、注册量连续增加、基差走弱、1—5价差收窄。

### 第4位：ICE超跌反弹与出口需求背离

- **方向/等级：双向，中低。**
- **事实：** USDA Crop Progress截至11/22美国棉花收获率84%，高于五年均值79%；USDA Cotton Ginnings截至11/15累计轧花约569.99万running bales，低于上年同期658.91万，约-13.5%。PCCA 11/23周报指出近期湿天气延误部分田间作业，分级报告出现更多bark、颜色等级下降和叶屑偏高。
- **区域：** 西德州High Plains/Hale County有局部收获延迟和质量担忧的产业报道；11/24冷锋给Texas Panhandle带来小范围雨雪/低温风险。该区域报道不能外推为全国损失。Delta和Southeast近期没有足以量化产量损失的最新公开证据。

### 完整成本公式

设：

- Psc=籽棉收购价（元/公斤）；
- y=净衣分/皮棉得率；
- l=加工损耗及杂质折减比例；
- Pseed=棉籽价格（元/公斤）；
- 加工费、运输、仓储、资金、保险、质量升贴水和税费分别为Gin、Freight、Storage、Finance、Quality、Tax。

每吨皮棉的成本可写为：
皮棉成本 = \[Psc×1000/y - Pseed×1000×(1-y-l)/y\] + Gin + Freight + Storage + Finance + Quality + Tax。

当前缺少同一批籽棉的实际净衣分、棉籽出率、损耗、水分、棉籽成交价、加工费、融资天数和质量升贴水，因此不输出伪精确成本点数。籽棉价格不能直接等同皮棉价格。

敏感性：

- 在衣分y为38%—40%的假设范围内，籽棉收购价每上涨0.10元/公斤，未扣棉籽副产品收益前，每吨皮棉原料成本约增加250—263元；该敏感度仅用于参数分析，不代表实际得率。
- 用户机采籽棉7.2—7.5元/公斤、亩产400公斤的毛收入为2,880—3,000元/亩；亩产下降100公斤，对应毛收入减少720—750元/亩。不能直接推导皮棉成本或全疆减产量。
