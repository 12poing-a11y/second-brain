### 4.5 用户自设2026/27基准：独立情景，不是官方预测

| 变量 | 用户设定 | 核验/说明 |
| --- | --- | --- |
| 产量 | 615万吨 | 用户假设，较USDA 729.4低114.4万吨 |
| 消费 | 780万吨 | 用户假设，较USDA 914.4低134.4万吨 |
| 期末库存 | 793万吨 | 用户假设 |
| 库消比 | 约43% | 与793/780不一致 |

**内部恒等关系：**

- 若期初库存810万吨、产量615、进口150、消费780、出口2，且无其他调整，则期末库存=810+615+150-780-2=793万吨，算术上可闭合。
- 若期初库存为上一年度某些国内表中的809万吨，同样进出口与消费假设下，期末库存为792万吨，需1万吨其他调整或舍入。
- 但793/780=**101.7%**，不是43%。若消费780、库消比43%，对应期末库存应约335.4万吨；若期末库存793、库消比43%，对应消费应约1,844万吨。
- 因此，793万吨可能是含国储/商业库存的广义总库存，而43%可能是剔除国储或采用其他消费口径的可用库存比；在定义澄清前，不把两个数放入同一平衡表。

### 4.6 用户减产与亩产情景敏感性

- 若新疆基准产量取650—680万吨，减产3.2%—4.0%对应减少20.8—27.2万吨；若采用行业估计710—720万吨，则减少22.7—28.8万吨。两组基数不可混用。
- 用户亩产情景：机采约400公斤/亩，较基准下降100公斤/亩。若400公斤/亩指籽棉单产，按衣分38%测算，皮棉产量约152公斤/亩；减产100公斤籽棉/亩相当于减少约38公斤皮棉/亩。
- 每覆盖100万亩，籽棉减产约10万吨、折皮棉约3.8万吨。覆盖面积尚未确认，因此不外推全国/新疆总减产量。
- 若400公斤/亩指皮棉单产，则上述换算不成立；必须先统一“籽棉亩产/皮棉亩产”定义。该项列为数据口径待核。
- 用户籽棉价情景：机采7.2—7.5元/公斤、手采8.5元/公斤，独立进入成本曲线，不重复叠加到官方产量调整。

## 8. 国内现货基差、进口利润与ICE→CF2701传导

### 8.1 现货与进口基准

- CC Index 3128B：16,778元/吨；CF2701日盘收15,390，现货基差1,388；CF2701结算15,340，结算口径基差1,438。
- FC Index M：88.25美分/磅；中国棉花信息网对应1%关税折价14,592元/吨、滑准税折价15,019元/吨。两者相差427元/吨。
- 3128B现货较1%关税进口折价高2,186元/吨；CF2701日盘收盘较1%关税进口折价高798元/吨。该差值不是无风险进口套利：品级、产地、配额、到港期、港杂、融资、检验、增值税和交割资格不同。
- 2027年89.4万吨关税配额中33%为国营贸易；配额可得性决定1%税率折算价能否实际落地。2026滑准税加工贸易30万吨，不自动代表2027配额。

### 8.2 ICE价格敏感度

换算公式：

- 1美分/磅 = 22.0462美元/吨。
- 按USD/CNY 6.6681，未计税费前约147.0元/吨/每1美分。
- 仅按1%关税和9%增值税的乘数近似，约161.8元/吨/每1美分；不含运费、保险、港口、融资、品质升贴水及配额稀缺溢价。

因此：

- ICE每上涨1美分/磅，机械进口成本约增加162元/吨；上涨2美分约324元/吨。
- USD/CNY每上升1%，按14,592元/吨进口基准估算，进口成本约增加146元/吨。
- 该敏感度是静态成本传导，不是CF2701必然同步上涨点数；国内基差和配额约束会改变传导比例。

### 8.3 进口平价公式与数据缺口

到岸/到厂成本结构：
ICE或外棉报价×汇率 + 海运/保险 + 品质升贴水 + 关税/配额成本 + 港口/检验 + 增值税 + 融资/仓储 + 内陆运输。

本报告使用FC Index M官方折算价作进口成本锚，不把ICE Dec26 78.80直接等同FC Index M 88.25。两者之间还包含现货基差、品质、产地和时间差。逐船运费、保险、配额影子价格、到港日期和港杂费用暂无可靠最新完整表，不能伪造单一精确进口利润。

## 9. 新棉成本曲线、纺织需求与替代纤维

### 9.1 皮棉成本公式

皮棉成本（元/吨）≈籽棉采购成本÷衣分－棉籽副产品抵扣+轧花加工/损耗+运输+仓储+融资+质量升贴水+税费。

机采棉演示参数（均为模型假设，不冒充实测）：

- 衣分38%，棉籽副产品率60%，棉籽价2.40元/公斤，加工/运输/仓储/融资等合计1,500元/吨皮棉。
- 成本=籽棉价×1,000/0.38－0.60×1,000/0.38×2.40+1,500。

| 籽棉价 | 模型皮棉成本 |
| --- | --- |
| 6.50元/公斤 | 14,816元/吨 |
| 6.87元/公斤 | 15,789元/吨 |
| 7.01元/公斤 | 16,158元/吨 |
| 用户情景7.20元/公斤 | 16,658元/吨 |
| 用户情景7.50元/公斤 | 17,447元/吨 |

手采棉演示参数：衣分40%、棉籽副产品率58%、棉籽价2.40元/公斤、加工与物流等1,800元/吨；籽棉8.50元/公斤对应皮棉成本约19,570元/吨。该值对衣分、棉籽价和质量等级高度敏感。

敏感性：

- 机采衣分38%时，籽棉价每上涨0.10元/公斤，皮棉成本约上升263元/吨。
- 棉籽价每上涨0.10元/公斤，按上述副产品率，皮棉成本约下降158元/吨。
- 用户机采籽棉7.20元/公斤下，衣分36%—40%变化可令成本约在15,900—17,500元/吨之间，说明衣分比单纯籽棉报价更关键。
- 当前棉籽价格暂无可靠最新值，2.40元/公斤仅作敏感性基准；未计入质量差异和具体税务处理。
