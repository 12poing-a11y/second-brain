# 订单块（Order Block）的交易特点与真实盈亏比

在你目前研究的量化交易框架中，订单块（Order Block，简称 OB）值得研究，但需要把三个问题分开：

1. **交易逻辑是否有效：** 订单块能否识别价格可能发生反转或加速的位置？
2. **盈亏比是否真实：** 扣除止损、手续费、滑点和假突破之后，策略实际能赚多少？
3. **能否量化验证：** 如何把订单块转化为可回测的交易信号，而不是事后看图、随意画区间？

先给结论：**订单块可以作为潜在支撑、阻力和入场位置的识别工具，但它本身不是经过验证的盈利策略。** 真正决定盈亏的，是订单块的筛选条件、入场确认、止损距离、交易成本，以及市场所处的趋势环境。

尤其要注意：图表上的订单块，不等于交易所能够直接观察到的真实机构挂单。订单块是技术分析中的价格结构概念，不能仅凭一段K线就断言机构在此处建仓，更不能据此认定价格一定会回到该区域。

## 一、订单块的核心交易特点

订单块主要来自 ICT（Inner Circle Trader）和 SMC（Smart Money Concepts，智能资金概念）交易体系。

其基本逻辑是：**寻找价格强势突破市场结构之前的最后一根反向K线，观察价格回到该区域后，是否出现延续原有方向的交易机会。**

| 形成条件 | 最后一根下跌K线附近，随后出现强势上涨 | 最后一根上涨K线附近，随后出现强势下跌 |
| 关键确认 | 价格向上突破前期结构高点 | 价格向下跌破前期结构低点 |
| 理想入场 | 价格回踩订单块后获得支撑 | 价格反弹至订单块后受到压制 |
| 止损位置 | 订单块下沿或结构低点下方 | 订单块上沿或结构高点上方 |
| 盈利目标 | 前高、流动性区域或更高一级阻力 | 前低、流动性区域或更低一级支撑 |
| 主要风险 | 下跌趋势中的假突破 | 上涨趋势中的假跌破 |

这里有一个重要区别：

**最后一根反向K线不一定是有效订单块。**

如果后续没有明显的价格位移，也没有突破前期结构，那么它可能只是普通K线。

实盘中，至少需要考察以下四个因素：

1. **市场结构突破（BOS）：** 是否真正突破了此前的关键高点或低点。
2. **价格位移（Displacement）：** 突破是否伴随明显的单向推动，而不是缓慢爬行。
3. **回踩质量：** 价格返回区域时，是快速拒绝，还是持续在区域内成交。
4. **高周期方向：** 订单块是否顺应更高周期的趋势，还是逆势交易。

其中，前两个因素用于定义订单块，后两个因素用于评估交易质量。

需要强调的是，这些是可供测试的技术条件，不代表它们必然带来正收益。

## 二、订单块究竟有什么优势和缺陷？

### 优势一：可以定义相对明确的止损位置

这是我认为订单块最值得利用的地方。

例如，假设郑棉 CF2701 出现一个多头订单块：

- 订单块上沿：16,200点
- 订单块下沿：16,000点
- 入场价格：16,150点
- 止损价格：15,980点

那么：

- 每吨价格风险：170元。
- 每吨目标盈利若为340元，则目标价格为16,490点。
- 名义盈亏比：2:1。

这套交易的优点不是能够准确预测价格，而是**在进场之前，就可以明确判断自己愿意承担多少损失，以及需要多大的潜在盈利才能值得交易。**

对于商品期货尤其重要，因为同一个订单块，可能因波动率不同而具有完全不同的风险。

### 优势二：能够与趋势和流动性分析结合

订单块单独使用时，可能只是一个价格区间。

但如果同时观察以下信息，其研究价值可能提高：

- 高周期趋势方向。
- 前高、前低及流动性扫荡。
- 成交量与持仓量变化。
- 波动率和市场状态。
- 关键价格区域的突破与回踩。

例如，价格先跌破前低，随后快速收回，形成向上结构突破，再回踩多头订单块。

这种情形可以作为一个待验证的多头交易模型。

不过，**价格扫荡并不必然意味着主力吸筹，持仓量变化也不能单独证明机构正在建仓。** 这些信号需要结合行情数据验证。

### 缺陷一：订单块的定义存在主观性

不同交易者可能画出不同的订单块：

- 有人采用整根K线的最高价与最低价。
- 有人只采用开盘价与收盘价。
- 有人要求突破前高或前低。
- 有人要求同时存在公平价值缺口（FVG）。
- 有人只接受首次回踩。

定义一变，入场价格、止损距离和胜率都会变化。

如果每次交易都根据图形临时调整规则，最终很容易产生选择偏差：成功的交易被解释为订单块有效，失败的交易则被解释为订单块画错了。

这会让策略看起来很漂亮，实际却无法稳定执行。

### 缺陷二：价格触及订单块，不代表一定成交

这是回测中很容易被忽略的问题。

假设你在订单块内设置限价买单，价格快速下跌后又迅速反弹。

历史K线显示价格曾触及你的挂单价格，但这不代表实际订单一定能够成交。真实成交还取决于排队位置、盘口深度和当时的成交顺序。

如果回测默认所有触价挂单都能成交，策略收益可能被高估。

### 缺陷三：趋势行情和震荡行情的表现可能不同

在强趋势中，价格可能只进行浅回踩，随后继续运行。

在震荡市场中，价格可能反复穿越多个订单块。

因此，订单块策略至少应该区分：

- 趋势延续交易。
- 震荡区间交易。
- 趋势反转交易。
- 高波动率事件交易。

不能假定一套入场规则在所有市场环境中都有效。

# 三、订单块的真实盈亏比究竟是多少？

这里必须先区分两个概念。

**名义盈亏比**是下单时预先设定的目标盈利与止损金额之比。

**实际盈亏比**则需要统计真实成交后的平均盈利与平均亏损，并扣除手续费、滑点等交易成本。

两者可能差别很大。

我查阅了近期公开的订单块回测资料。现有测试的策略定义、市场、周期和交易成本各不相同，结果也有明显差异。

这些结果来自公开的独立回测文章，并非经过统一方法复核的学术共识。它们不能直接用于预测郑棉或其他中国商品期货的表现。

但它们足以说明一个关键问题：

**订单块的图形识别能力，不等于订单块策略的盈利能力。**

目前没有充分依据可以给出一个适用于所有品种、所有周期的订单块真实胜率或真实盈亏比。

## 2. 真正需要计算的是交易期望值

量化交易中，最重要的不是单看胜率，而是每笔交易的数学期望。

假设：

- 胜率为 $p$ 。
- 平均盈利为 $W$ 。
- 平均亏损的绝对值为 $L$ 。
- 每笔交易平均成本为 $C$ 。

那么：

 $E=pW-(1-p)L-C$

其中， $E$  是每笔交易的平均预期净利润。

如果使用风险单位  $R$  进行统一计算，假设：

- 平均亏损为1R。
- 平均盈利为2R。
- 平均交易成本为0.05R。

则：

 $E=2p-(1-p)-0.05$

整理得到：

 $E=3p-1.05$

当  $E=0$  时：

 $p=\frac{1.05}{3}=35\%$

也就是说，在这组假设下，**胜率必须高于35%，策略的数学期望才为正。**

这里的0.05R是用于演示的假设成本，并非郑棉实际手续费或滑点数据。

### 不同盈亏比下的盈亏平衡胜率

下表假设交易成本为零，且所有交易的平均盈利、平均亏损均严格符合设定值。

| 平均盈利/平均亏损 | 盈亏平衡胜率 |
| --- | --- |
| 1:1 | 50.00% |
| 1.5:1 | 40.00% |
| 2:1 | 33.33% |
| 3:1 | 25.00% |
| 4:1 | 20.00% |

注意，表中的1.5:1是指盈利为亏损的1.5倍。

这些数值只是数学上的盈亏平衡条件，并不意味着盈亏比越大越好。目标设得越远，实际到达目标的概率通常也需要重新评估。

## 四、为什么图表上2:1的盈亏比，实际可能只有1.2:1？

考虑一笔订单块交易：

- 入场价格：16,150点。
- 止损价格：15,980点。
- 目标价格：16,490点。

名义风险为170点，名义盈利目标为340点。

因此，名义盈亏比为2:1。

但实际交易中可能发生：

1. 止损时出现跳价，实际亏损超过170点。
2. 止盈前价格反转，交易者提前退出。
3. 手续费和滑点侵蚀盈利。
4. 部分止盈导致平均盈利低于目标。
5. 连续交易产生额外的执行成本。

如果最终统计得到：

- 平均盈利：280点。
- 平均亏损：200点。

那么实际平均盈亏比就是：

 $\frac{280}{200}=1.4$

这还没有考虑额外的交易费用。

所以，量化研究必须分别记录：

- 计划盈亏比。
- 实际平均盈利。
- 实际平均亏损。
- 扣除成本后的平均净利润。
- 盈亏平衡胜率。
- 最大连续亏损。
- 最大回撤。

**真正有价值的是长期扣除成本后的正期望，而不是截图上漂亮的2:1。**

# 五、如果把订单块用于你的量化研究台，我建议怎么做？

结合你目前研究的商品期货、趋势识别和风险控制，我不建议单独开发一个只负责画订单块的指标。

更合理的方向是建立一个可回测的订单块交易模块，并与现有的趋势、动量、波动率和资金风险模块结合。

## 1. 订单块质量评分

先建立一个0—100分的初始评分框架。

| 评分维度 | 权重 | 评估内容 |
| --- | --- | --- |
| 高周期趋势 | 25 | 交易方向是否与高周期趋势一致 |
| 结构突破 | 25 | 是否突破此前关键高点或低点 |
| 价格位移 | 20 | 突破幅度是否相对于ATR足够显著 |
| 回踩质量 | 15 | 回踩后的拒绝、收盘位置及停留时间 |
| 成交量与持仓量 | 15 | 是否存在与价格变化相符的量仓信号 |
| **合计** | **100** | — |

这些权重是研究用的初始参数，不是经过验证的最优参数。

还需要设置一个重要限制：成交量和持仓量不能被简单解释为机构方向。例如，价格上涨而持仓量下降，可能反映空头回补，而非新增多头资金入场。

此外，订单块的评分必须在交易时点使用当时已经可获得的数据计算，不能事后根据价格走势修改评分。

## 2. 建立三种入场方式进行对照

不要一开始就把所有过滤条件混在一起，否则很难知道收益究竟来自哪里。

| 模型 | 入场规则 | 研究目的 |
| --- | --- | --- |
| A：直接回踩 | 价格触及有效订单块后挂限价单 | 测试订单块本身是否具有优势 |
| B：结构确认 | 触及订单块后，等待低周期出现方向确认 | 测试确认条件能否改善收益 |
| C：趋势过滤 | 只交易符合高周期趋势的订单块，并要求回踩确认 | 测试趋势过滤是否改善风险调整后收益 |

三个模型必须使用相同的样本区间、交易成本假设、风险预算和评价指标。

否则，即使C模型表现更好，也不能确定优势来自趋势过滤，还是来自其他参数差异。

## 3. 重点验证真实盈亏比

每种模型至少输出以下指标：

| 指标 | 作用 |
| --- | --- |
| 交易次数 | 判断样本是否充足 |
| 胜率 | 观察盈利交易占比 |
| 平均盈利R | 测量盈利交易的平均收益 |
| 平均亏损R | 测量亏损交易的平均损失 |
| 实际盈亏比 | 平均盈利除以平均亏损绝对值 |
| 单笔净期望R | 评估每笔交易扣除成本后的收益 |
| Profit Factor | 总盈利除以总亏损绝对值 |
| 最大回撤 | 评估资金曲线风险 |
| 最大连续亏损 | 评估策略连续失效的承受能力 |
| 样本外表现 | 判断策略是否可能过拟合 |

我还会额外记录一个指标：

**订单块的增量收益。**

例如，先运行普通趋势回踩策略，再运行加入订单块过滤后的策略。如果两者表现几乎相同，说明订单块可能只是重复识别了已有的趋势回踩信号，并没有提供新的预测信息。

这比单纯证明订单块策略能够赚钱更有价值，因为它可以帮助你判断，是否值得增加系统的复杂度。

## 六、最终判断

我的观点比较明确：

1. **订单块适合用作价格结构定位工具。** 它能够提供相对明确的观察区域和止损参考。
2. **订单块不应被视为独立的盈利优势。** 公开回测结果存在明显差异，没有一个可以直接套用到郑棉的可靠通用胜率。
3. **2:1的名义盈亏比不代表真实收益。** 必须统计实际成交、平均盈利、平均亏损和交易成本。
4. **最值得研究的是订单块能否提高现有策略的增量收益。** 如果不能，就没有必要因为技术概念流行而把它塞进量化系统。

### 对你而言，下一步最值得做的事

我建议将订单块加入你的研究台，作为独立的候选信号模块，与现有的趋势过滤、动量识别、ATR止损和风险管理系统进行对照测试。

第一阶段不急于实盘交易，而是先回答三个问题：

- 订单块是否能提高入场后的收益期望？
- 等待低周期确认，是否值得牺牲部分入场价格？
- 在国内商品期货中，订单块是否对不同品种、不同市场状态都有效？

**如果经过样本外测试、交易成本压力测试和不同市场状态验证后，订单块仍然能够提高净期望与风险调整后收益，再考虑将它升级为正式的交易信号。**

这才是把技术分析真正转化为量化研究，而不是把图表上的故事包装成策略。
