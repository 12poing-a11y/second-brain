## 铁律

1. **每页三字段**：Claim / Source / Confirmed（+ Status）  
2. **矛盾不静默覆盖** → disputed + 问人  
3. **30 天无新来源** → unconfirmed  
4. **先做一个主题**：中国期货 CTA 路径A  
5. 好答案必须回写成 wiki 页  

## 周日例行（15 分钟）

1. CTA 周回测  
2. 跑 Checker → `wiki/_checks/YYYY-MM-DD-check.md`  
3. 清 Notion Inbox / `00-Inbox/`
